段落を組み立てる

要の1文・組み立て方の型・具体性

この章で分かること
  • 1つの段落の基本形
  • 要の1文の5つの型
  • 見出しの種類ごとの組み立て方（24種）
  • つなぎ言葉の使い分け
  • 具体的に書く4つのコツ

3.1 段落の基本形

1つの見出しの下は、合わせて300〜400字（段落1〜2つ）で書きます。1つの段落には1つの役割だけを持たせ、次の順で組み立てます。

  1. 言い切る：その段落で言いたいことを最初の1〜2文で書く（「私は〜という方針を策定した」）
  2. 理由・背景：なぜそうしたか（「〜だからである」）
  3. 具体：中身・数字・固有の事情
  4. 結果・つなぎ：その結果どうなったか、次の見出しへのつなぎ

結論を最初に書くと、採点者が「この段落は設問の何に答えているか」をすぐ判断できます。

3.2 要の1文の5つの型

段落の中で最も大事な1文（要の1文）の多くは、次の5つの型に当てはまります（「刷新は、」「推進体制は、」のように、言い切る内容から始まる文もあります）。前の文を読んで、次にどの型が来るかを決めてから書くと、迷わず書けます。

書き出し役割例（A社）
このため、事業特性や現状を、経営への影響につなぐこのため、発注の精度が欠品と廃棄の量を左右し、利益に直結する。
この結果、課題を、経営課題（客数・食品ロス）につなぐこの結果、…新しい施策に時間と費用が掛かり、経営課題への対応が遅れていた。
そこで私は、自分の判断・工夫・改善を言い切るそこで私は、業務への影響が小さい順に段階的に移す計画とした。
その結果、調整や改善で得たもの（協力・合意・承認）を示すその結果、店舗運営部は先行店舗の選定と手順書づくりに協力することになった。
数字効果や結果を、比較の相手とともに示す試行した3店舗では、比較した3店舗に対して廃棄率が2.1%から1.4%に下がった。

3.3 見出しの種類ごとの組み立て方

見出しの種類によって、書く順番はほぼ決まっています。アプリの段階学習 段階4で横に表示される組み立て方と同じです。

見出しの種類組み立て方（この順に書く）
事業概要と事業特性
  1. 会社の概要を数字で（業種・店舗数・売上・従業員）
  2. 「事業特性は、次の2点である」と予告する
  3. 第一に〜。このため〜（特性→経営上の意味）
  4. 第二に〜。このため〜
現状と課題
  1. 現状（いつ・何が・どうなっている）
  2. その結果起きている問題（数字）
  3. 経営・事業への影響（このままでは〜）
方針・企画の内容
  1. 方針を一文で言い切る（私は〜という方針を策定した）
  2. 中身（新しい構造・技術・範囲・進め方）
  3. 検討した別案と、選んだ理由（事業特性と結び付ける）
必要性と有効性
  1. 必要性：このままでは〜になる（だから今〜が必要）
  2. 有効性：〜することで〜できる（数字）
  3. 経営課題とのつながり（〜の解決に直結する）
技術とデータ活用の具体化
  1. 何のデータで何をするか（技術）
  2. どこで動かすか（自社開発／外部サービス）
  3. 業務の流れと人の役割
  4. 変革への貢献（効率化で止めない）
特に重要と考えて工夫したこと
  1. 重要と考えたことと、その理由（懸念・困難）
  2. 工夫の中身（何を・どのように）
  3. なぜそうしたか（ねらい）
  4. 結果（数字・関係者の反応）
変革の阻害要因
  1. 阻害要因を2〜3点に絞る（第一に〜）
  2. それぞれ、放置すると変革がどう止まるか
  3. 最も重視した要因と理由
事業部門との交渉・調整
  1. 誰が・何を懸念・反対したか（理由も）
  2. 私の対応（データを示す・試行・役割分担）
  3. 合意・協力を得た内容
経営層への説明
  1. 説明した論点（効果・費用・リスク）
  2. 根拠となる数字
  3. 経営層に求めた判断
評価・意思を受けて改善したこと
  1. 経営層（事業部門）の評価・指摘・意思
  2. それを受けて変えた内容（計画・体制・KPI）
  3. 結果（承認・その後の進み方）
DXの狙いと施策
  1. 経営課題（数字）
  2. DXの狙い（何をどう変えるか）
  3. 施策の内容（何をするか）
新たな情報技術とその必要性
  1. 検討対象の技術（何か）
  2. 従来の技術・やり方では実現できなかったこと
  3. だからこの技術が必要（事業特性と結び付ける）
机上確認・技術検証
  1. 確認・検証の観点（何を確かめるか）
  2. 方法（資料・試行・比較の相手）
  3. 結果（数字）
  4. 経営・事業の観点での評価
リスクとその対策
  1. リスク（何が起きると、事業や経営にどう影響するか）
  2. 対策（予防と、起きたときの対応）
  3. 経営層が認識すべき点
事業戦略
  1. 経営課題・環境変化
  2. 事業戦略（何を目指すか）
  3. テーマ（ビジネスモデル等）が必要になった理由
顧客と提供価値
  1. 対象顧客（誰か・どんな困りごとか）
  2. 提供価値（顧客から見た言葉で）
  3. 既存事業の強みとのつながり
製品・サービスと収益の獲得方法
  1. 価値を具現化する製品・サービス
  2. 運営の仕組み（既存資源の活用）
  3. 収益の得方（何で・いくら）
  4. 実現可能性（目標と根拠）
当初の要件とのかい離
  1. 当初の想定（数字）
  2. 想定したかい離（増える・減る・偏る）
  3. 放置した場合の影響
分析の対象となる業務とITシステム
  1. 対象の業務（誰が・いつ・何をする）
  2. 対象のITシステム（機能と使われ方）
  3. 業務とシステムの関係（どこで判断に使うか）
改修要望と利用部門の問題認識
  1. 改修要望の内容（具体的に）
  2. 利用部門の問題認識（何に困っていると考えているか）
  3. 要望が部分的である可能性（利用部門の視点だけ）
収集した情報
  1. 何の情報を（要望・業務・システム・利用状況）
  2. どこから・どうやって（データ・観察・ヒアリング）
  3. 利用部門以外のステークホルダからも集める
分析の内容
  1. 全社視点の観点（他部門・上流下流・ステークホルダ）
  2. 分析した結果（数字）
  3. 利用部門の認識とのずれ
特定した問題の真因
  1. 真因を一文で言い切る（要望＝真因にしない）
  2. 真因と、要望・問題との因果
  3. 要望どおり改修しても解決しない理由
対応方針
  1. 解決手段（真因に効くもの）
  2. スケジュールと実行体制（誰が何を）
  3. 投資と効果（数字）
  4. 当初の要望の扱い（採用・見送りと理由）

3.4 つなぎ言葉の使い分け

役割言葉使いどころ
並べる第一に、第二に、第三に課題・理由・施策を2〜3個示すとき。数を先に予告する（「次の2点である」）
原因→結果このため、この結果、これにより事業特性→課題、施策→効果
自分の判断そこで私は、私は〜と考えた工夫・方針・改善の書き出し。ITストラテジストとしての判断を示す
結果その結果、協議の結果、調整・試行・改善の後
対比一方、しかし2案の比較、良い結果の後の課題
追加あわせて、さらに、また同じ役割の内容を足すとき（使いすぎない）

3.5 具体的に書く4つのコツ

① 数字を入れる

悪い例食品ロスが大きく、利益を圧迫していた。
良い例生鮮品の廃棄が売上の2%、年16億円に達し、利益を圧迫していた。

② 比較の相手を書く

悪い例試行の結果、廃棄率が大幅に改善した。
良い例試行した3店舗では、立地の近い3店舗と比べて、廃棄率が2.1%から1.4%に下がった。

③ A社ならではの事情を書く

悪い例一般に、長年改修を重ねたシステムは保守が難しい。
良い例仕組みを知る社員は2名だけで、数年で定年を迎える。

④ 主語を「私」にする

悪い例段階的に移行することとなった。
良い例そこで私は、業務への影響が小さい順に段階的に移す計画とした。

午後IIは「あなたの経験と考え」を問う試験です。自分が判断したことは、主語を「私は」にして書きます。

3.6 文の書き方

  • 文末は「である」調にそろえる。「です・ます」と混ぜない。
  • 1文が長くなりすぎたら（目安として80字を超えたら）、2文に分ける。
  • 「〜と考える」「〜と思われる」を続けない。判断は言い切る。
  • 同じ言葉を1文の中で繰り返さない（「〜を行い、〜を行った」「〜であることである」）。
  • 読点は「、」で統一する。
よくある失敗
  • 一般論で始め、A社の事情が出てこない（「一般に〜」「昨今〜」）
  • 箇条書きのように短い文を並べ、つながりがない
  • 「〜こととなった」と主語がなく、自分の判断に見えない
  • 結果を「大幅に改善」「好評だった」で済ませる

確認問題

答えを考えてから「答え」を開いてください。

問1　次の空欄に入る書き出しはどれですか。「仕組みを知る社員は2名だけで、数年で定年を迎える。（　　）、障害の原因すら特定できなくなり、発注が止まるリスクが高まる。」

答え
「このため、」（または「この結果、」）です。現状（2名・定年）から、事業への影響（発注が止まる）につなぐ文なので、原因→結果の言葉を使います。

問2　「経営層の評価を受けて改善したこと」の見出しで、最初に書く文はどれが適切ですか。
ア 経営層に丁寧に説明した。　イ 社長からは〜という評価を受けた。　ウ 一般に経営層は投資に慎重である。

答え
イです。組み立て方は「評価・指摘 → 変えた内容 → 結果」の順です。アは改善になっておらず、ウは一般論です。

問3　「新しいシステムを導入し、業務が大幅に効率化された。」を具体的に直してください。

答え
例：「需要予測の仕組みを導入した結果、発注作業時間は1店舗1日90分から40分に減り、その時間を売場づくりに充てられるようになった。」（何を・数字・比較・その後の効果）
